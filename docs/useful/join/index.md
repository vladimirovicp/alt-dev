# Join


## Списки рассылок

Перед началом рекомендуется подписаться и ознакомиться с архивом рассылок, так как вы далеко не первый человек, который решил пройти данный процесс. Велика вероятность, что ответы на ваши вопросы уже содержатся в предыдущих письмах.

> * [devel-newbies](https://lists.altlinux.org/mailman/listinfo/devel-newbies) - Эта рассылка может рассматриваться как отправная точка для новичков. В списке devel-newbies участники ALT Linux Team оказывают поддержку начинающим мейнтейнерам, отвечают на часто задаваемые вопросы, связанные с разработкой и сборкой пакетов. Кроме того, именно здесь можно выразить желание пройти join и найти себе ментора.
>
> * [Community](https://lists.altlinux.org/mailman/listinfo/community) - Нововсти и обсуждения в сообществе.
>
> * [Sisyphus](https://lists.altlinux.org/mailman/listinfo/sisyphus) - Обсуждения вопросов, связанных с Sisyphus
>
> * [Devel](https://lists.altlinux.org/mailman/listinfo/devel) - Список рассылки ALT Linux Team, предназначенный для обсуждения вопросов разработки.
