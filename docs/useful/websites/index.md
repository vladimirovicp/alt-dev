# Вебсайты

* [Форум сообщества Альт Линукс](https://forum.altlinux.org/)
* [Список пакетов ALT Linux](https://packages.altlinux.org/ru/sisyphus/ ) - это информационно-аналитический сайт для разработчиков и пользователей репозитория Sisyphus, а также бранчей (стабильных срезов репозитория Sisyphus, на основе которых и создаются все дистрибутивы ALT Linux).
* [Bugzilla](https://bugzilla.altlinux.org/) - место куда надо сообщать о замеченных вами ошибках, также здесь можно оформить запрос на сборку нового пакета в Сизиф или бранч.
* [ALT Linux Space](https://altlinux.space/) - Место для обсуждения, разработки и развития свободных проектов. От создателей одного из крупнейших репозиториев свободного программного обеспечения Sisyphus («Сизиф»), предназначенного для семейства операционных систем «Альт».

* [Документация ALT Linux Team](https://docs.altlinux.org/)
* [Вики-документация сообщества](https://www.altlinux.org/)
* [Альт академия](https://kurs.basealt.ru/)
* [Сайт загрузки ALT](https://getalt.org/)
* [Git-хостинг](https://git.altlinux.org/)


## Wiki

* [ALT Gnome Wiki](https://alt-gnome.wiki/) - база знаний операционных систем: ALT Regular Gnome, ALT Starterkit Gnome и Альт Рабочая станция
* [ALT KDE Wiki Communit](https://alt-kde.wiki/) - открытое сообщество пользователей операционной системы ALT Regular KDE
* [ALT Mobile Wiki](https://altmobile.org/) - это база знаний по операционной системе ALT Mobile, имеющая открытый исходный код и развиваемая сообществом.
