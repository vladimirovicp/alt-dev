## 0.19.0-alt1
**Дата выпуска** : 04.03.2025

## 0.18.0-alt1
**Дата выпуска** : 05.12.2024

Новое :
-   Добавлены настраиваемые разрешения во вкладку безопасности: создание/удаление дочерних объектов, чтение/запись свойств.
-   Добавлены задачи делегирования во вкладку безопасности — стандартные задачи из RSAT.
-   Расширенные права вынесены в отдельную вкладку.
-   Стандартные и общие разрешения теперь разделены и дополнены: просмотр содержимого, чтение/запись всех свойств, удаление, изменение владельца и др.
-   Добавлен выбор области применения разрешений: только текущий объект, объект и дочерние элементы, только дочерние или дочерние определённого класса.
-   Изменено поведение отключения прав: отключение родительского права приводит к отключению всех дочерних.
-   Добавлены действия "Установить всё / Снять всё" и "Редактировать" для вкладки связей политик в OU-виджете.

Исправления :
-   Исправлены тесты, падавшие из-за некорректного выбора контроллера домена.
