# Релизы

## 0.0.5-alt2
**Дата выпуска** : 06.05.2025

Изменения :
-   Удалена зависимость libgvdb-gir, так как автоматический поиск зависимостей теперь работает корректно.
-   Файлы локализации перемещены в стандартный каталог /usr/share/locale/.
-   Перепакованы переводы; добавлено автодополнение команд в bash через pyproject.toml.
